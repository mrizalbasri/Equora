# Brand Assets & Metadata

## Logo (`equora-logo.webp`)
`equora-logo.webp` is the transparent 1254 × 1254 logo supplied on 22 October 2026. It is used in shared public and workspace headers and as the web favicon.

## Social & Open Graph Preview (`equora-og.jpg`)
`equora-og.jpg` is the high-resolution 1024 × 576 social card and Open Graph preview image (supplied on 11 November 2026). It contains the Equora brand mark, the tagline *"Wawasan Data untuk Indonesia"*, the dashboard overview showing 38 provinces, and the map of Indonesia. It is referenced in:
- `og:image` and `og:image:secure_url` (Open Graph standard)
- `twitter:image` with `summary_large_image`
- Schema.org (`WebSite`, `Organization`, `WebApplication`)
- Google Image Sitemap (`sitemap.xml`)

The supplied visual reference and dashboard mockup are design and promotional representations; official quantitative figures are always loaded dynamically from published datasets.
